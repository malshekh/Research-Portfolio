# **FTLD Graduate Research Project**
## Welcome!

This repository is a collection of laboratory protocols, experimental workflows, troubleshooting notes, and research documentation from wet-lab studies on Frontotemporal Lobar Degeneration (FTLD) Tau and TDP-43 protein biology.

Contents include:
- Labratory protocols and troubleshooting notes
- Protein information using bioinformatics tools
- pyMOL visualizations
- Experimental workflows
- Research documentation
